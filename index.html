מה האוטומציה עושה

  • מי שמגיבה מילת מפתח על פוסט או ריל מקבלת אוטומטית הודעה בפרטי עם מה שהבטחת: קישור, מדריך, פרומפט.
  • מתחת לתגובה שלה מופיעה תשובה קצרה, כמו "שלחתי לך בפרטי 💌". בכל פעם נוסח אחר, כדי שלא ייראה כמו העתק-הדבק.
  • אפשר להחזיק כמה מילים במקביל, מילה לכל פוסט, וכל מילה שולחת משהו אחר.
  • זה רץ 24 שעות ביממה, גם כשהמחשב כבוי, בלי מנוי.

מה צריך לפני שמתחילות

  • חשבון אינסטגרם מקצועי (עסקי או יוצרת). בודקות באינסטגרם: הגדרות ← סוג חשבון וכלים.
  • מחשב. מהטלפון ההגדרות קשות מדי.
  • חשבון פייסבוק, בשביל אתר המפתחים של Meta.
  • חשבון אינסטגרם נוסף (של חברה, או שני שלך), כדי לבדוק בסוף.
  • בערך שעה בפעם הראשונה. אחר כך, מילה חדשה לוקחת שתי דקות.
1

פותחות חשבון Cloudflare

Cloudflare הוא המקום שבו השרת הקטן יגור. התוכנית החינמית מספיקה בגדול: עד 100,000 בקשות ביום.

  1. נכנסות ל-dash.cloudflare.com/sign-up ונרשמות עם המייל. לא צריך כרטיס אשראי.
  2. מאשרות את המייל שהם שולחים.

יוצרות את השרת ומדביקות את הקוד

  1. ב-Cloudflare: Workers & Pages ← Create ← Start with Hello World!.

הקוד של השרת 
// ============ ההגדרות שלך: משנים רק כאן ============

// מילה באנגלית שאת ממציאה (בלי רווחים). את אותה מילה תדביקי אחר כך ב-Meta.
const VERIFY_TOKEN = `my-secret-word-2468`;

// המספר של החשבון שלך באינסטגרם (מופיע ב-Meta מתחת לשם המשתמש).
// ככה התגובות שלך עצמך לא מפעילות כלום. עד שיש לך אותו, משאירים ריק.
const MY_ACCOUNT_ID = ``;

// מילות המפתח. לכל מילה: מה נשלח בפרטי, ותשובות קצרות מתחת לתגובה (נבחרת אחת באקראי).
// מילה חדשה = מעתיקות בלוק שלם מ-{ עד }, מדביקות מתחתיו ומשנות. כל הטקסטים בין גרשיים הפוכים ` `
const RULES = [
  {
    keyword: `מדריך`,
    dm: `היי! איזה כיף שכתבת 🙌
הנה המדריך שהבטחתי:
https://example.com

נתקעת? כתבי לי, ואעזור לך 😊`,
    replies: [
      `שלחתי לך בפרטי 💌`,
      `מחכה לך בפרטי ✨`,
      `נשלח! תציצי בהודעות 😊`,
      `שלחתי 🙌 לא רואה? תבדקי בבקשות ההודעות`,
    ],
  },
];

// ============ מכאן והלאה לא נוגעים ============

export default {
  async fetch(request, env, ctx) {
    const url = new URL(request.url);
    if (url.pathname === '/privacy') return privacyPage();
    if (url.pathname !== '/api/webhook') return new Response('Not found', { status: 404 });

    if (request.method === 'GET') {
      const q = url.searchParams;
      if (q.get('hub.mode') === 'subscribe' && q.get('hub.verify_token') === VERIFY_TOKEN) {
        return new Response(q.get('hub.challenge'));
      }
      return new Response('wrong verify token', { status: 403 });
    }
    if (request.method !== 'POST') return new Response(null, { status: 405 });

    const raw = await request.text();
    if (!(await signatureOk(raw, request.headers.get('x-hub-signature-256'), env.APP_SECRET))) {
      console.warn('bad signature: check APP_SECRET (it must be the Instagram app secret)');
      return new Response(null, { status: 401 });
    }
    let body;
    try { body = JSON.parse(raw); } catch { return new Response(null, { status: 400 }); }

    const jobs = [];
    for (const entry of body.entry || []) {
      for (const change of entry.changes || []) {
        if (change.field === 'comments') jobs.push(onComment(change.value || {}, env));
      }
    }
    // answer Meta right away, keep sending in the background
    ctx.waitUntil(Promise.allSettled(jobs));
    return new Response('EVENT_RECEIVED');
  },
};

async function onComment(c, env) {
  const from = c.from || {};
  if (MY_ACCOUNT_ID && from.id === MY_ACCOUNT_ID) return;
  const words = (c.text || '').toLowerCase().match(/\p{L}+/gu) || [];
  const rule = RULES.find(r => words.includes(r.keyword.toLowerCase()));
  if (!rule) return;

  console.log(`keyword "${rule.keyword}" from @${from.username || from.id}`);
  await send(env, '/me/messages', { recipient: { comment_id: c.id }, message: { text: rule.dm } });
  if (rule.replies && rule.replies.length) {
    const reply = rule.replies[Math.floor(Math.random() * rule.replies.length)];
    await send(env, `/${c.id}/replies`, { message: reply });
  }
}

async function send(env, path, payload) {
  const r = await fetch(`https://graph.instagram.com/v23.0${path}`, {
    method: 'POST',
    headers: { Authorization: `Bearer ${env.IG_TOKEN}`, 'Content-Type': 'application/json' },
    body: JSON.stringify(payload),
  });
  if (!r.ok) console.error(`${path} failed: ${r.status} ${await r.text()}`);
}

async function signatureOk(raw, header, secret) {
  if (!secret || !header || !header.startsWith('sha256=')) return false;
  const key = await crypto.subtle.importKey('raw', new TextEncoder().encode(secret),
    { name: 'HMAC', hash: 'SHA-256' }, false, ['verify']);
  const sig = new Uint8Array((header.slice(7).match(/../g) || []).map(h => parseInt(h, 16)));
  return crypto.subtle.verify('HMAC', key, sig, new TextEncoder().encode(raw));
}

function privacyPage() {
  return new Response(`<!doctype html><html lang="he" dir="rtl"><meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1"><title>מדיניות פרטיות</title>
<body style="font-family:Arial,sans-serif;max-width:640px;margin:40px auto;padding:0 16px;line-height:1.7">
<h1>מדיניות פרטיות</h1>
<p>השירות הזה עונה אוטומטית למי שמגיבה על הפוסטים שלי באינסטגרם במילת מפתח, ושולח לה הודעה בפרטי.</p>
<p>המידע שמתקבל מאינסטגרם (טקסט התגובה ומזהה המשתמשת) משמש רק כדי לשלוח את ההודעה, ולא נשמר ולא מועבר לאף אחד.</p>
<p>לבקשה למחוק מידע, אפשר לשלוח לי הודעה בפרטי באינסטגרם.</p>
</body></html>`, { headers: { 'Content-Type': 'text/html; charset=utf-8' } });
}

ממלאות את ההגדרות שלך, בראש הקוד

  1. VERIFY_TOKEN: ממציאות מילה באנגלית, בלי רווחים. רושמות אותה בצד, צריך אותה בשלב 5.
  2. keyword: המילה שעוקבות יכתבו בתגובות.
  3. dm: מה שנשלח בפרטי. כאן שמים את הקישור למה שהבטחת. אפשר לרדת שורה.
  4. replies: התשובות הקצרות מתחת לתגובה. כדאי כמה נוסחים שונים בסגנון שלך.
שומרות על הסימנים. כל טקסט נמצא בין שני גרשיים הפוכים `. כותבות רק ביניהם, ולא מוחקות פסיקים או סוגריים. בתוך הטקסט עצמו לא משתמשות בגרש הפוך.

לוחצות Deploy. למעלה מופיעה הכתובת של השרת, משהו כמו auto-dm.שם-שלך.workers.dev. מעתיקות אותה בצד. ממנה יוצאות שתי כתובות:

עמוד הפרטיותהכתובת עם /privacy בסוף. העמוד כבר בנוי בתוך הקוד.
3

אפליקציה ב-Meta

זה החלק הארוך. Meta צריכה "אפליקציה" שדרכה השרת מקבל את התגובות ושולח הודעות. היא שלך, ורק החשבון שלך מחובר אליה.

המסכים של Meta משתנים מדי פעם. אם משהו נראה אחרת ממה שכתוב כאן, מצלמות מסך ושואלות צ'אט AI "איפה אני לוחצת עכשיו?".

יוצרות את האפליקציה

  1. נכנסות ל-developers.facebook.com עם חשבון הפייסבוק. בפעם הראשונה הוא מבקש להירשם כמפתחת, זה כמה לחיצות.
  2. My Apps ← Create App. נותנות שם, למשל auto-dm.
  3. במסך ה-Use cases בוחרות Manage messaging & content on Instagram.
  4. אם הוא שואל על Business portfolio, אפשר לבחור שעוד לא מחברות. ממשיכות עד Create app.

מוסיפות את עצמך כבודקת

  1. בתפריט: App roles ← Roles ← Add People ← Instagram Tester, וכותבות את שם המשתמש שלך באינסטגרם.
  2. מאשרות את ההזמנה מתוך אינסטגרם: במחשב, ב-instagram.com ← הגדרות ← Apps and websites ← Tester invites ← Accept.

מחברות את החשבון ומקבלות טוקן

  1. בתפריט: Use cases ← Customize ← API setup with Instagram login.
  2. ב-Generate access tokens: Add account, מתחברות לאינסטגרם, ואז Generate token.
  3. מעתיקות את הטוקן ומדביקות מיד ב-Cloudflare (שלב 4). הוא נראה כמו שורה ארוכה של אותיות ומספרים.
  4. באותו עמוד למעלה, ליד Instagram app secret, לוחצות Show ומעתיקות. גם הוא הולך ל-Cloudflare.
  5. מתחת לשם המשתמש שלך מופיע מספר ארוך. זה המספר של החשבון שלך. מעתיקות אותו לקוד, בין הגרשיים של MY_ACCOUNT_ID, ולוחצות Deploy. ככה התגובות שלך עצמך לא מפעילות כלום.
זהירות, יש שני "סודות" שונים. צריך את ה-Instagram app secret מהעמוד הזה. יש עוד App secret בהגדרות הכלליות של האפליקציה, ואיתו השרת ידחה את כל התגובות.
4

מכניסות את הסודות ל-Cloudflare

הטוקן והסוד הם כמו סיסמה לחשבון שלך. מדביקות אותם רק כאן, ולא בתוך הקוד. לא שולחות אותם לאף אחד, גם לא לצ'אט AI.

  1. ב-Cloudflare: Workers & Pages ← השרת שלך ← Settings ← Variables and Secrets ← Add.
  2. לכל אחד בוחרות סוג Secret, ממלאות שם וערך:
NameValue
IG_TOKENהטוקן משלב 3
APP_SECRETה-Instagram app secret משלב 3

בסוף לוחצות Deploy.

5

מחברות את Meta לשרת

  1. חוזרות לעמוד API setup with Instagram login ← Configure webhooks.
  2. Callback URL: כתובת השרת עם /api/webhook בסוף. Verify token: המילה שכתבת ב-VERIFY_TOKEN. לוחצות Verify and save.
  3. בטבלת Webhook fields מדליקות את comments.
  4. למעלה, ב-Generate access tokens, בודקות שליד החשבון שלך Webhook Subscription במצב On.
מתג שחוזר אחורה? לוחצות על מתג אחד, מחכות כמה שניות, ומרעננות את הדף לוודא שהוא נשאר דלוק. לחיצות מהירות על כמה מתגים ברצף לפעמים לא נשמרות.
6

מעבירות את האפליקציה ל-Live

כל עוד האפליקציה במצב פיתוח, Meta שולחת לשרת רק תגובות של מי שמוגדרת בה. כדי שזה יעבוד לכל העוקבות:

  1. App settings ← Basic: ב-Privacy Policy URL מדביקות את כתובת עמוד הפרטיות משלב 2. שומרות.
  2. בתפריט: Publish ← Publish.

לחשבון שלך עצמך זה עובד בלי תהליך בדיקה של Meta. אם בכל זאת תופיע בקשה ל-App Review, זה תהליך של כמה ימים, וממלאים אותו לפי ההוראות שם.

7

בודקות שזה עובד

  1. מהחשבון השני כותבות את המילה מתחת לפוסט.
  2. תוך כמה שניות: הודעה בפרטי בחשבון השני, ותשובה קצרה מתחת לתגובה.
  3. לא הגיע? פותחות את היומן: ב-Cloudflare ← השרת ← Observability. כל תגובה שזוהתה מופיעה שם עם המילה, וכל שגיאה מופיעה באדום. מה כתוב שם, מחפשות בטבלה למטה.

מילה חדשה לפוסט חדש

מעכשיו, לכל פוסט עם מתנה בפרטי מוסיפים מילה:

  1. ב-Cloudflare: השרת ← Edit code.
  2. ברשימת RULES מסמנות בלוק שלם של מילה, מה-{ ועד ה-}, שסוגר אותו, ומעתיקות.
  3. מדביקות מיד אחריו, ומשנות במילה החדשה את keyword, את dm ואת replies.
  4. Deploy, ובודקות מהחשבון השני.

כל מילה עובדת על כל הפוסטים. לכן נותנים לכל פוסט מילה משלו, ולא מילה שתופיע בתגובות רגילות. "תמונה" למשל תפעיל את האוטומציה גם אצל מי שכותבת "איזו תמונה יפה".

האוטומציה עובדת רק על תגובות שנכתבו אחרי שהיא הופעלה. לתגובות ישנות עונים ידנית.

חשוב לדעת

  • הודעה אוטומטית אחת לכל תגובהזה הכלל של Meta. תוכן ארוך שמים בעמוד, ושולחים קישור.
  • הטוקן פג אחרי 60 יוםקובעות תזכורת ביומן. כשמגיע הזמן: Generate token שוב, ומחליפות את IG_TOKEN ב-Cloudflare.
  • התגובות שלך לא מפעילות כלוםהשרת מדלג על החשבון שלך, כדי שתוכלי לענות בחופשיות.
  • לא סומכות על קישורים זמנייםמה ששולחים בפרטי צריך להישאר זמין גם בעוד חודש: עמוד באתר שלך או בשרת עצמו.
נתקעת באמצע? מצלמות מסך ושואלות צ'אט AI (Claude או ChatGPT) "איפה אני לוחצת עכשיו?". רק בלי להדביק לו את הטוקן או הסוד.
